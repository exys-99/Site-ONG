<h2 id="sobre">📄 Sobre o Projeto</h2>

<p>
  Esse site foi um projeto da faculdade, na disciplina de Back-End, no 1º período de Ciências da Computação, onde consistia em desenvolver uma plataforma web completa e profissional para ONGs.
  <br>
  O objetivo da atividade foi de criar um site profissional para que ONGs e outros tipos de associações possam se inserir no ambiente digital.
</p>

<h2 id="funcionalidades">✨ Funcionalidades Principais</h2>

<p>O JavaScript implementado oferece diversas funcionalidades essenciais para a experiência do usuário:</p>
<ul>
  <li>Acessibilidade (ARIA):Implementação de atributos aria-expanded e controle de foco para navegação e submenus.</li>
  <li>Alternância de Tema: Funcionalidade de Modo claro/escuro e alto Contraste</li>
  <li>Máscaras de Inpu Aplicação automática de máscaras para CPF, Telefone e CEP nos campos de formulário.</li>
  <li>Menu Hamburguer: Navegação responsiva e gerenciamento do estado de abertura da navegação</li>
  <li>Sub-menus Acessíveis:Lógica para abrir/fechar submenus de forma intuitiva, especialmente em dispositivos móveis.</li>
  <li>Gerenciamento de Modais:** Funções para abrir e fechar modais usando atributos 'data-modal-open' e 'data-modal-close'.</li>
</ul>
